GitHub 上传说明

当前仓库：https://github.com/dwaker-cller/dataset_dealer （Public，分支 main，账号 dwaker-cller）

仓库内容
- README.md、requirements.txt、上传说明.txt、.gitignore
- Algorithm、指标抽取工作台Demo、成果示例 三个文件夹
- 2025主网项目指标参考(1).xlsx 指标模板

已通过本机 git 推送，无需在网页逐个上传。后续更新命令：
  cd datasets_dealer
  git add -A
  git commit -m "说明本次改动"
  git push

网页上传方式（无法使用 git 时）
1. 登录 GitHub，确认账号为 dwaker-cller。
2. 进入仓库，选择 Add file > Upload files。
3. 将 README.md、requirements.txt、上传说明.txt、.gitignore、2025主网项目指标参考(1).xlsx 以及 Algorithm、指标抽取工作台Demo、成果示例三个文件夹一起拖入网页。
4. 填写提交说明，例如“上传造价指标工作台及核验成果”，点击 Commit changes。
5. 核对 README.md 位于仓库根目录，三个子文件夹与指标模板均已出现。

注意：造价数据（约 2.2 GB）与 models/ 不在仓库内，已在 .gitignore 排除，运行前须在仓库根目录自行准备。ZIP 用于保存和传递本次成果。

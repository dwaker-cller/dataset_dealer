# 工程指标抽取工作台

## 当前版本：五工程累计展示（2026-10-28）

双击 `启动工作台.bat`，或打开 http://127.0.0.1:18864 。点击工程数据源路径右侧的“…”；窗口默认打开“造价数据”，选择常州茅山、扬州秀清、徐州沛县、连云港菩提、江苏镇江圌山中的具体工程文件夹；选择配套 Excel 模板及 OWL 后，先点击“检查配置”，再点击“开始抽取”。

结果按工程累计到模板表格，一工程一行。更换工程后重新检查、开始即可追加；重复工程更新原行。点击单元格查看当前行所属工程的来源。随时导出当前已完成工程，导出后可以继续追加；导出的文件不会反向自动更新，再导出可获得完整新版。“清空累计结果”开始新批次。刷新页面会清空本页累计结果，请先导出需要保留的成果。

本版本使用真实资料整理的预置结果，点击时核验来源，不新增模型推理/OCR。支持原配套模板的字段结构与批注口径、配套OWL，不支持任意模板的通用抽取。未包含表示本演示未整理出可回填证据。详情见《实测说明.md》最新章节。

以下为旧版历史记录，不作为当前操作说明。

2026-10-04更新：已接入秀清真实资料取值。当前能力及范围以《实测说明.md》为准；以下为旧版交互Demo说明，留作开发记录。

双击 `启动工作台.bat`，在本机浏览器打开工作台。服务地址为 http://127.0.0.1:18864 。

1. 分别选择工程文件夹、Excel 模板（xlsx）、OWL 指标文件，也可直接粘贴路径。
2. 点击“检查配置”，读取文件清单、模板表头和 OWL 定义。
3. 点击“开始抽取”，体验处理流程，可暂停、继续和取消。
4. 在“模板结果”中切换工作表、横向浏览、点击单元格查看指标定义。
5. 点击“导出 Excel”，生成带模板表头的 xlsx。缺失字段填写“未包含”。原模板及工程资料不会被修改。

## 本版实际能力

已接通：Windows 文件/目录选择、真实文件清单扫描、xlsx 工作表及多级表头/批注读取、项目所用 RDF/XML OWL 指标读取、基础字段映射、模板预览、xlsx 文件生成。

本版用于交互效果确认：解析、OCR、模型抽取阶段使用前端流程演示；结果金额来自固定交互样本，不是从所选文件中提取。没有实际加载或调用 Qwen3.5-9B，也不产生真实来源证据。界面按用户要求不添加模拟标签。导出的样本不得用于工程造价分析或模型准确率评价。

下一版接口位置：`app.js` 的 start 流程接入实际任务状态；`server.py` 的 result_rows 替换为 document_parser / self_extraction 的真实任务结果。

模板适配边界：识别 A 列首个数字序号之前的表头；无序号时读取前 6 行。适配本项目五张工作表模板及相近结构。导出保留工作表名称、表头内容和合并结构、近似列宽与标题颜色；不复制模板中原有的 955 行项目值，也不承诺保留任意 Excel 对象、宏或复杂格式。

运行使用本机 Codex bundled Python/openpyxl（只读模板）及 Node/artifact-tool（生成 Excel）；不联网下载依赖。输出文件保存在本目录 outputs。
